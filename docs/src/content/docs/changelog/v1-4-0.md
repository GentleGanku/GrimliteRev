_15 October 2026_

**Grimlite Rev** returns with a new update to address several issues arose after the recent **Game Release (9 Oct 2026)**. This update introduces visual features, bug patches, and adjustments while retiring a couple of old disfunctional features.

As a quick detour, the plan is to have several updates up for release to keep **Grimlite Rev** up with the current trend and competitions. No promises, but expect more visual features, new bot commands, and experiments (inspired from my unreleased bot client). 

As a side note, **Grimlite Rev** was made to accompany and inspire so many people/botters (including me, since the early 2020) to play the game without having to waste countless days just for a single item. Nowadays, so many other bot clients are made and still maintained just to help those same people. It's pretty cool, I'd say.

## CHANGELOGS

### ADDITIONS

- Added a "NEW!" badge to recently updated Main Menu tabs, informing of whether there are updates to their internal/external. This will be available for v1.4.0 and the next versions.
- Added a new Discord tab in Main Menu, redirecting you to the static Discord server invitation when clicked ([https://discord.gg/NZ6vmDTu44](https://discord.gg/NZ6vmDTu44)).
- Added a new Support Me! tab in Main Menu, redirecting you to the Ko-fi donation page when clicked ([https://ko-fi.com/gentleganku](https://ko-fi.com/gentleganku)).
- Added a new Settings tab in Main Menu, providing settings to enable in modifying user interface or features. Settings are saved in the BotClientConfig.cfg file.
- Added a new Camouflage setting in Main Menu -> Settings tab, modifying the user interface so that it renders with the official Artix Launcher appearance when enabled.
- Added a new Shortcuts hyperlink in Bot Manager -> Left Side, opening a new app window regarding the shortcuts available to be used for managing bot commands and such.
- Added innate conditional checks to bot commands, such as Bank Transfer, Buy Item, and Accept Drop, to realign with the game's functionality.
- Replaced the game background on Login and Loading screens with a new background (see: /fableforest).
- Replaced the hyperlink for "Donate to support the project!" with a new URL ([https://ko-fi.com/gentleganku](https://ko-fi.com/gentleganku)).
- Replaced the Custom Commands checkbox in Bot Manager with a hyperlink, functioning the same as before. When enabled (previously: checked), the hyperlink gets a green highlight, and otherwise gray highlight instead.

### PATCHES

- Fixed the Packet Network not returning any packet messages back to the app client at all.
- Fixed the Bot Manager not working properly for most functions.
- Fixed the post-login Bank Load not working properly on some occasions.
- Fixed the Inventory Slot counts not calculated properly on some bot commands.
- Fixed the Buy Item commands not working properly when executed with the Manual mode.
- Fixed the Buy Item commands not ignoring its confirmation modal when executed.

### OTHERS

- Removed Main Menu -> Get Bots tab.
- Removed Main Menu -> More tab.
- Removed Main Menu -> Options tab -> Provoke Monsters in Map option. This will have no effect to the coexisting .gbot files; nothing's applied when used.
- Removed Main Menu -> Options tab -> Auto-save State. This will have no effect to the coexisting .gbot files; nothing's applied when used.
- Removed Bot Manager -> Options tab -> Provoke Monsters in Map option. This will have no effect to the coexisting .gbot files; nothing's applied when used.
- Removed Bot Manager -> Options tab -> Auto-save State. This will have no effect to the coexisting .gbot files; nothing's applied when used.
- Removed Bot Manager -> Misc tab -> Provoke Monster in Map section. This will have no effect to the coexisting .gbot files; nothing's executed when used.
- Various other bug fixes/adjustments.
