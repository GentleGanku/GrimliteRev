What's coming to Grimlite Rev and when. A feature starts as a proposal, moves up next once it's picked for a version, then to in progress while it's built, and to released when it's done. Miscellaneous covers what keeps Grimlite Rev running well: fixes after game updates, speed and stability.

Vote for the features you want most: one vote each, and clicking again takes it back. Want something that isn't here? Suggest it under Proposed, or talk it through on the [Discord server](https://discord.gg/NZ6vmDTu44).
